1. **Clear DB** — MongoDB Atlas → delete all documents in `workerprofiles`, `companyprofiles`, `jobs`
2. **Create Company A** (BuildRight) → Admin approves
3. **Create Company B** (SwiftServe) → Admin approves
4. **Create Worker 1** (Member 1's PAN) → PAN verify + email OTP → Admin approves
5. **Create Worker 2** (Member 3's PAN) → PAN verify + email OTP → Admin approves
6. **Create Worker 3** (Member 4's PAN) → PAN verify + email OTP → Admin approves
7. **Post Job A** from BuildRight
8. **Post Job B** from SwiftServe
9. **Post Job C** from BuildRight
10. **Complete Job A** — Worker 1 applies → BuildRight accepts → escrow → Start OTP + before photo (take real photo) → End OTP + after photo → payment released → both rate 5 stars
11. **Stage Job C dispute** — Worker 3 applies → BuildRight accepts → escrow → Start OTP + before photo → Worker 3 raises dispute with above reason → leave it
12. **Fund all wallets** with devnet SOL from solfaucet.com
13. **Do a dry run** of the live Job B flow once before demo day
